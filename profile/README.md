# NLT

NLT staat voor Natuur, leven en technologie, een profielkeuze vak op de middelbare school. 

In deze GitHub organisatie staan al enkele online modules en een template. Door middel van deze GitHub organisatie en de online modules is het makkelijker om onderhoud te plegen aan de bestaande modules, maar ook interactiviteit te embedden in de modules.

* Ben je nieuw hier en werkzaam als auteur? Bekijk dan de [introductie voor auteurs](https://github.com/NLT-modules/Voor-Auteurs)
* Wil je meteen aan de slag? Gebruik dan het [template](https://nlt-modules.github.io/Template/)
* Wil je weten hoe zo'n online module er uit kan komen te zien? Bekijk dan de [schakelmodule](https://nlt-modules.github.io/Schakelmodule/)
